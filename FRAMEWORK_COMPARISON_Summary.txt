FRAMEWORK CHARACTERISTICS
================================================================================

GDPR (42 Requirements)
──────────────────────
Structure:      Legal regulation (EU law)
Focus Areas:    • Data protection principles
                • Processor responsibilities (Art 28)
                • Security of processing (Art 32)
                • Data subject rights (Art 15-22)
                • Breach notification (Art 33)
                • Third-country transfers (Art 44-49)
Scope:          Data protection compliance
Mandatory:      YES - EU processor obligation
Certification:  No - regulatory requirement
Audit Type:     Compliance audit
Coverage:       71% of ISAE 3000 controls

ISO 27001:2022 (116 Controls)
──────────────────────────────
Structure:      International security standard
Focus Areas:    • Information security management
                • Technical controls
                • Organizational governance
                • Access and identity management
                • Incident management
                • Supplier management
                • Physical security
                • Continuity planning
Scope:          Information security management
Mandatory:      NO - voluntary standard
Certification:  YES - ISO certification available
Audit Type:     Management system audit
Coverage:       95% of ISAE 3000 controls

================================================================================
COMPLEMENTARY STRENGTHS
================================================================================

GDPR Focuses On (What ISO May Not Cover Deeply):
  ✓ Data subject rights (access, deletion, portability)
  ✓ Breach notification requirements
  ✓ Data processing agreements with processors
  ✓ Third-country transfer mechanisms
  ✓ DPIA requirements
  ✓ Data Protection Impact Assessments

ISO Focuses On (What GDPR May Not Cover Deeply):
  ✓ Information security governance
  ✓ Asset management and inventory
  ✓ Physical security controls
  ✓ Human resource security (screening, training)
  ✓ Incident management processes
  ✓ Vendor/supplier management
  ✓ Business continuity and disaster recovery
  ✓ Configuration management
  ✓ Application security and SDLC
