# ISAE 3000 - Document Upload Requirements with GDPR References

**For each document required in Column D "Document to upload"**
**Suggested GDPR Cyberday Reference Point**

## A – CONTROLLER INSTRUCTIONS

### A.1 - Processing Instructions & Procedure Review

| Document to Upload | GDPR Reference Point | Cyberday Framework |
|---|---|---|
| Current procedure for processing under controller instructions | **Art 28(3)(a)** - Processor must process only on documented instructions from controller | Art 28 - Data processor |
| Current system description or processing overview, with changes since last review | **Art 30** - Records of processing activities showing processing scope and changes | Art 30 - Records of processing |
| Annual compliance calendar or dated record of latest procedure review | **Art 32(2)** - Measures appropriate to risk; annual review requirement | Art 32 - Security of processing |

### A.2 - Compliance with Processing Agreements

| Document to Upload | GDPR Reference Point | Cyberday Framework |
|---|---|---|
| Current register or overview of processing activities from which sample can be selected | **Art 30** - Maintain records of processing activities | Art 30 - Records of processing |
| For 3 processing activities: applicable DPA and controller instructions with processing records | **Art 28(3)(a)** - DPA must contain documented instructions | Art 28 - Data processor |

### A.3 - Reporting Potentially Unlawful Instructions

| Document to Upload | GDPR Reference Point | Cyberday Framework |
|---|---|---|
| Procedure for assessing and escalating instructions that may breach data protection law | **Art 28(3)** - Processor responsible for security and compliance; implied duty to assess lawfulness | Art 28 - Data processor |
| Case record and dated controller notification, if any; otherwise confirmation no such cases occurred | **Art 33** - Notification of breach (implied: assessment capability); if no cases: confirmation | Art 33 - Notification of breach |
